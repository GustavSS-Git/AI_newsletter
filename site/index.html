Research

Anthropic releases open-source FlashProve to verify which model produced an output

Anthropic published FlashProve, a prototype that uses cryptographic proofs to show an output came from a specific model without revealing its weights. Anthropic says one H100 GPU generates proofs at about 110 tokens per second for Llama 4 Maverick, at roughly 70 to 95 times the GPU time of running the model. Code and specifications are on GitHub under the Apache 2.0 license. TechCrunch reports there are no plans to deploy it at Anthropic or any other lab.

Why it matters: The work targets the inability of users to confirm that a provider served the model it claimed, such as when a cheaper one is swapped in.

Sources: TechCrunch AI, Anthropic, NewsCord, Benzinga
